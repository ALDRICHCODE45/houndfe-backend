# Showcase catalog: image credits (toys, hygiene, accessories, habitats)

Photos used by `scripts/ops/showcase-catalog/products/toy-hygiene-accessory-habitat.cjs`. The loader downloads each URL and uploads it to Spaces; this page keeps the attribution the licenses require.

- **Source:** every photo comes from Wikimedia Commons. None is a manufacturer product shot or an AI image.
- **Licenses:** all allow commercial use: Public domain, CC0, CC BY 2.0/3.0/4.0 and CC BY-SA 2.0/3.0/4.0. CC BY and CC BY-SA need attribution (author, license, link). CC BY-SA also asks that changed versions keep the same license; the loader uploads the photos unchanged.
- **Illustrative photos:** they show the kind of product or pet, not the exact branded item.
- **URLs:** they point to the 1280 px Commons rendition (or the original when it is smaller). All 60 were checked on 2026-11-09 with the engine's `probeImage`: each answered HTTP 200 with `image/jpeg`.
