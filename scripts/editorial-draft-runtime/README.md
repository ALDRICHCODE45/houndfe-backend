# Disposable draft runtime — parent-owned only

Requires explicit runtime/cleanup consent, cached pinned PostgreSQL 16 image, existing dependencies and a verified isolated `dist` build. Never use AppModule, existing databases, production credentials or port 3000. Use a new empty owner-only `.tmp/draft-runtime.*` directory (`RUN` below); never reuse a failed target.
Run `env -i PATH=/usr/bin:/bin /usr/bin/python3 scripts/editorial-draft-runtime/setup.py "$RUN"` in a background job. It replays all 72 migrations separately; stop on failure, without retrying migrations or claiming Prisma deployment-ledger equivalence. PostgreSQL has only its owned internal bridge and no published port; configuration port0 means unbound, not a valid Prisma target.
Run `env -i PATH=/usr/bin:/bin NODE_ENV=development /absolute/installed/node scripts/editorial-draft-runtime/host.cjs "$RUN"` as an owned background job. The API owns a loopback-only ephemeral TCP relay to the identity-verified container IP: eight clients maximum, bounded admission/connect time, identity rechecked before each connection, no arbitrary destination. Only its live listener supplies the strict Prisma binding. Real Auth/editorial/CLS are used; development password login is existing policy. Seeder and fixture writes stay in the disposable DB. Internal networking blocks external routing, not all communication with host services; Docker administrator compromise is outside this proof.
Setup and relay validate the exact data-directory `HostConfig.Tmpfs` configuration, even when Docker reports an empty `Mounts` array. A gatewayless internal endpoint is accepted only with the owned network's valid IPv4 IPAM gateway; inconsistent nonempty endpoint gateways remain rejected.
After `ready.json`, run the same sanitized Node command with `probe.cjs`; this exercises real login, draft writes, replay, negative cases and authenticated reopen. Browser verification separately uses the untouched browser fixture and requires permission for the exact new credential file; an old-path grant does not transfer. Never print credentials or substitute responses.
Stop only the owned API job, then run sanitized Python with `retire.py "$RUN"`; host shutdown first closes the relay and sockets, bounds application/client cleanup and records matching start/stop identities. Retirement requires that evidence when a host started, rechecks resource ownership, removes only its container/network/credential files and preserves proof. Missing shutdown evidence or uncertain identity requires manual reconciliation, never arbitrary PID killing or blanket cleanup.
Run `/absolute/installed/node --test scripts/editorial-draft-runtime/relay.test.cjs` for offline regression checks (injected Docker observations and real loopback sockets, never Docker). Retain sanitized invalid-root checks for all four CLIs and optimized-Python rejection. Syntax/offline/native review does not establish runtime success.
This proves only observed sequential draft behavior against synthetic/custom vocabulary. It does not prove the 68-code catalog, OTP delivery, full AppModule startup, production DB privileges/RLS, concurrency, publication or C3.3. Runtime execution and independent verification are still required.
